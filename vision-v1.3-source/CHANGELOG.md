# 更新记录

## v1.3 — 图标、边缘交互与连续逐帧

- 使用用户提供的 PNG 作为软件、快捷方式和安装器图标，保留原色。
- 播放/暂停/停止/上一/下一/打开改用独立矢量图标，方形控件加细分隔线。
- 添加 5 逻辑像素黑色操作边框，八方向缩放命中与箭头光标；全屏/最大化隐藏外圈。
- 添加多个 vision 窗口在拖动时吸附对齐，不操作其他应用窗口。
- 左右键单击真实逐帧，长按连续逐帧，松开/失焦停止追加。
- 引擎改用事件唤醒；空闲不周期轮询，正常刷新和逐帧检查分别使用 100/20 ms。
- 完成安装目录与截图分析，明确没有取得 PotPlayer 主程序源码，未复制代码。

## v1.2 — 启动文件修复与精简无边框界面

- 启动时直接读取 Windows Unicode 命令行，保留中文、空格和文件 URL；文件路径先排队，播放引擎就绪后加载。
- 默认无系统标题栏，改为 30 px 窄标题栏、20 px 进度/音量栏、40 px 单排播放控制（逻辑像素）。
- 打开视频按实际显示尺寸计算窗口，考虑旋转和 DPI，整个窗口最大不超过当前屏幕可用范围；不恢复旧版的大窗口尺寸。
- “原尺寸”恢复完整画面并重新适配窗口，不再启用会裁切画面的 video-unscaled=yes。
- 视频区域与窗口边缘齐平，去除重复工具条与额外左右边距。窄窗口自动收起次要按钮，功能保留在菜单。
- 保留逐帧快捷键、声道、音轨、字幕、倍速、收藏、列表、截图、默认播放器安装选项。
- 增加离屏界面和冷启动检查，覆盖 Unicode 路径、旋转视频、竖屏、4K、100%/125%/150%/200% DPI。

## v1.1 — 画面、列表与播放控制改进

- 右键新增“原尺寸”：恢复原始宽高比并按实际显示像素呈现，取消放大、裁切填满和缩放偏移；“画面比例”恢复适应窗口。
- 安装结束页新增默认播放器复选框，默认不勾选；勾选后打开 Windows 默认应用中 vision 的确认页面。注册六种视频格式，卸载清理自身注册。
- 置顶改为灰色横向 / 黄色竖向图钉，按钮和快捷键同步状态。
- 打开列表向右扩展窗口，关闭后收回；空间不足或最大化/全屏时使用独立列表面板，保持视频区域大小。添加列表、历史、收藏搜索。
- 新增停止并回到开头、上一/下一视频、快捷打开、设置和列表工具按钮。
- 显示实际软/硬解、视频/音频编码和输出声道；可点击查看播放详情或切换声道。
- 新增系统推荐、单声道、立体声、多声道及源输出共 20 种声道选择，保存到本地设置。
- 按用户要求不加入 360°、3D、虚拟环绕及杜比虚拟解码。

## v1.0 — 首个手动验收版本

- 实现六种本地视频格式的播放、暂停、跳转和 0.25–4 倍速。
- 实现真实逐帧与请求排队，左右键前后步进；修复连续按键重复暂停中断帧步进的问题。
- 实现音轨、内嵌/外挂字幕、音画及字幕同步、截图与画面比例。
- 实现深色蓝色 UI、全屏、置顶、小窗、无边框、多显示器选择。
- 实现本地 JSON 设置、SQLite 历史收藏和续播、可关闭历史记录。
- 生成当前用户离线 exe 安装器，卸载保留用户数据，安装完成不自动启动。
