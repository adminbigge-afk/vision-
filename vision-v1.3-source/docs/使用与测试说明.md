# vision v1.3 使用与测试说明

关闭旧版本后运行 vision-v1.3-setup-x64.exe 安装。当前用户离线安装，所有依赖随包附带，不要求另外安装 Qt 或解码器。安装结束不会自动启动播放器。

## 本版重点

1. 在资源管理器双击已关联给 vision 的视频，应直接播放。启动路径支持中文、空格以及 file URL，先接收路径，再等待引擎就绪。也可以拖入视频或按 Ctrl+O 打开。
2. 打开视频默认精简无边框。窗口按视频的实际显示尺寸、方向和当前屏幕 DPI 计算；超出屏幕时连同标题栏及控制栏一起等比例限制，完整保留视频画面。
3. 右键“原尺寸（不超出屏幕）”恢复原始比例并重新计算窗口，不裁切。源视频自带的黑边仍是画面的一部分；全屏或手工改变窗口比例时，播放器保留比例而不强行拉伸。
4. 顶部：vision 菜单、文件名、置顶、最小化、最大化、全屏、关闭。可拖动顶部文件名区域移动窗口；边缘可调整大小。置顶状态为灰色横向/黄色竖向图钉。
5. 底部：进度和音量，一排播放/暂停、停止、上一/下一视频、打开、时间、解码信息、列表、设置和菜单。窄窗口自动收起次要按钮，仍可在右键菜单使用。

## 操作

- 空格：播放/暂停。← / →：真实上一帧/下一帧，步进后保持暂停；按住 350 ms 后连续逐帧，松开停止追加。
- Ctrl+← / →：后退/前进 30 秒。F 全屏，Esc 退出；M 静音，↑ / ↓ 或滚轮调音量。
- 双击画面全屏；单击播放/暂停。停止回到开头并暂停，上一/下一视频在当前队列切换。
- 右键菜单：音轨、字幕、播放速度、画面比例、截图、同步、收藏、窗口、播放信息、设置及输出声道。
- Ctrl+Shift+O 加载字幕，也可拖入 SRT/ASS/SSA/VTT/SUB；Ctrl+S 保存当前帧截图。
- 列表支持播放队列、历史、收藏和搜索。空间允许时向右扩展，不压缩视频；空间不足时显示独立列表面板。
- 输出声道有系统推荐、单声道、立体声、多声道及源输出选项。实际结果受系统混音器与音频设备影响，增加通道数不代表生成真实环绕录音。

## 安装与数据

安装结束页可勾选“设为默认视频播放器”，点击完成后在 Windows 默认应用页面完成确认。未勾选时不打开设置、不修改既有默认播放器。

设置/历史/收藏在 %LOCALAPPDATA%/vision；升级保留数据，卸载保留个人记录，不删除视频。不上传视频或播放记录。

## 手动验收

- 双击带中文和空格名称的视频，确认自动加载并播放；再测试拖放和 Ctrl+O。
- 分别打开横屏、竖屏、4K、带旋转元数据的视频，检查首次窗口完整落在屏幕中，比例正确，不裁切，标题栏和底部控件未被遮住。
- 检查真实显示器、125%/150%/200% DPI、多显示器、全屏恢复、列表、置顶与窗口拖动。
- 检查真实音频设备、硬解、逐帧、字幕、截图、续播及默认应用确认。

自动化检查使用离屏 Qt 界面、空音视频输出和临时测试数据，不操作用户桌面或系统默认应用。通过离屏测试不等于已经验证真实 GPU 窗口、音频设备或安装过程。

## v1.3 新增

外圈 5 逻辑像素黑边用于鼠标缩放，四边是水平/垂直箭头，四角是斜向箭头。拖动顶部文件名区域，靠近另一 vision 窗口会吸附对齐，继续拖远即可分离；只对本版 vision 窗口生效。

左右键单击上一/下一帧；按住 350 ms 后连续前后逐帧。释放或窗口失焦后停止新请求，已经在解码中的一帧可能随后完成。Ctrl+左右仍是 30 秒跳转。

请手动测试两个窗口的相邻边和上下对齐、八方向实际拖动、松手停止逐帧、桌面/任务栏软件图标。
