# vision v1.1 验证记录

## 已执行
- Windows x64 Release 构建通过，应用与安装器版本 1.1.0.0。
- 16 个媒体样本全部返回 0：MP4/MKV/AVI/MOV/WebM/FLV、CFR/VFR、24/23.976/25/30/29.97/50/60/59.94 FPS、多音轨/字幕。
- 验证实际前后帧时间戳、跨 GOP、快速帧请求队列、倍速不影响逐帧、字幕/音频同步、本地存储。
- 原尺寸属性重置宽高比、panscan、zoom，并能恢复适应窗口。测试等待渲染参数重配置稳定后开始逐帧。
- 20 种音频输出布局被引擎接受；空音频设备上确认实际 mono=1、stereo=2 声道转换。
- NSIS 编译通过；7-Zip 完整性检查和解包通过；解包后的 vision.exe 与构建输出 SHA256 一致。
- 默认关联采用 HKCU 注册、独立 ProgID 和 Windows 设置 URI；没有写 UserChoice，默认复选框未勾选。卸载只清理自己的关联注册。
- 原 v1.0 安装器 SHA256 未改变。
