# vision v1.2 验证记录

- Windows x64 Release 构建通过，运行时标题 vision v1.2，安装器/PE 资源版本 1.2.0.0。
- 16 组播放回归全部通过：六种格式，CFR/VFR，23.976/24/25/29.97/30/50/59.94/60 FPS，多音轨、字幕、实际逐帧、跨 GOP、排队、倍速与本地存储。
