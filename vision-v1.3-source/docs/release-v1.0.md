# vision v1.0 交付记录

日期：2026-09-09。用户已授权继续完成所有阶段并直接交付 exe 安装包，安装和实际桌面播放由用户手动测试；此前各阶段等待确认的流程已由该指令替代。

## 已实现

C++20 / Qt Widgets / libmpv 原生播放器；深色界面与 #005fff 点缀；六种视频容器、播放暂停、精确跳转、倍速、真实前后逐帧、音轨与内嵌/外挂字幕、同步偏移、截图、比例、全屏/小窗/无边框/置顶、多屏全屏选择；JSON 设置、SQLite 历史收藏与续播；当前用户离线 NSIS 安装器。

逐帧请求在引擎中串行执行。修复回归发现的重复暂停取消正在进行的 frame-step 问题：只有进入逐帧序列时暂停，之后按键入队，不干扰当前帧解码。长按默认不产生重复快捷键。

## 自动检查与限制

- Release 配置、编译与链接通过，PE x64 GUI 子系统与 v1.0 版本资源已检查。
- CoreChecks 用 `vo=null`、`ao=null`、软件解码运行，无可见窗口、无音频输出、不播放用户个人视频。
- 基准来自独立 FFmpeg 解码的展示时间戳；验证 23.976、24、25、29.97、30、50、59.94、60 FPS 及变化帧间隔素材。
- 验证前进 15 帧、后退 15 帧、跨 GOP、往返定位、2 倍速下单帧步长及连续请求排队。验证 MP4/MKV/AVI/MOV/WebM/FLV 样片。
- 验证多音轨选择、内嵌字幕开关、音画/字幕偏移设置；JSON 原子写入、数据库重新打开、收藏保留及清空历史的行为通过测试。
- libmpv 与 Vulkan 下载档案已按发布方 SHA256 核对；安装器离线包含运行库、插件和许可证。

所有无窗口测试仅证明对应代码路径、解码时间戳与存储行为，不能代替真实屏幕画面、声音、截图内容或显卡路径验证。尚未运行用户安装向导、实际 GUI、GPU 4K/8K、多屏/DPI 或真实音画同步性能测试。安装包未数字签名；本版为交给用户手动验收的 v1.0。
